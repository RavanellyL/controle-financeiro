Sistema de Controle Financeiro

### Aplicação Full Stack com Assistente de Inteligência Artificial

Sistema web desenvolvido para gerenciamento e acompanhamento de finanças pessoais, reunindo controle de receitas, despesas, orçamentos, metas financeiras, investimentos e uma Assistente de Inteligência Artificial em uma única plataforma.

O projeto tem como objetivo oferecer uma experiência intuitiva para organização financeira, utilizando tecnologias modernas de desenvolvimento web, integração de APIs e banco de dados relacional.

Dashboard Financeiro

A aplicação possui um painel interativo que permite acompanhar as informações financeiras de maneira organizada.

**Principais recursos:**
- Visualização de receitas, despesas e saldo total.
- Gráficos comparativos de receitas e despesas.
- Distribuição de gastos por categorias.
- Histórico de transações financeiras.
- Filtros por período, categoria e tipo de transação.
- Cadastro, edição e exclusão de movimentações.
- Identificação de pagamentos realizados.
- Alertas de limites orçamentários excedidos.

Assistente de Inteligência Artificial

O sistema conta com uma área dedicada à Assistente de IA, integrada à aplicação.

Essa funcionalidade amplia os recursos da plataforma e representa a aplicação prática de Inteligência Artificial em um sistema de gerenciamento financeiro.

Arquitetura do Sistema

O projeto utiliza uma arquitetura Full Stack, com separação entre interface, API e banco de dados.

Frontend (React + TypeScript)**

Responsável pela interface, navegação, formulários, gráficos e interação com o usuário.

**Backend (Python + FastAPI)**

Responsável pelo processamento das requisições, autenticação, validação de dados e regras de negócio.

Banco de Dados (PostgreSQL)

Responsável pelo armazenamento e gerenciamento das informações financeiras.

A aplicação também possui integração com uma Assistente de Inteligência Artificial.

Testes Automatizados

Foram implementados testes automatizados utilizando pytest, com foco na validação do funcionamento da API.

Resultados:
- 13 testes automatizados aprovados.
- Testes de autenticação.
- Testes de operações CRUD.
- Verificação de funcionalidades da API.

Segurança e Qualidade

Foram utilizadas ferramentas de análise de segurança e auditoria de dependências.

Bandit: análise estática de código Python para identificação de possíveis problemas de segurança.

pip-audit: verificação de vulnerabilidades conhecidas nas dependências Python.

Também foram aplicadas práticas de autenticação, proteção de rotas e organização do código.
